# My To-do ♡ — نسخه قابل نصب (PWA)

این بسته، همان فایل HTML اصلی را با کمترین تغییر به PWA تبدیل می‌کند.

## فایل‌ها
- `index.html` — برنامه‌ی اصلی
- `manifest.webmanifest` — نام، آیکون و حالت نمایش برنامه
- `sw.js` — ذخیره‌ی فایل‌های اصلی برای اجرای آفلاین
- `icons/` — آیکون‌های 192 و 512 پیکسلی

## نکته مهم
برای نصب روی اندروید و ویندوز، برنامه باید از یک آدرس HTTPS باز شود.
باز کردن مستقیم `index.html` از حافظه با آدرس `file://` برای نصب PWA کافی نیست.

## انتشار با GitHub Pages
1. یک مخزن (Repository) جدید در GitHub بساز.
2. تمام محتویات همین پوشه را در ریشه‌ی مخزن بارگذاری کن؛ خود پوشه‌ی `My-To-do-PWA` را داخل مخزن قرار نده، بلکه فایل‌های داخل آن را بارگذاری کن.
3. در مخزن وارد Settings → Pages شو.
4. در بخش Build and deployment، گزینه‌ی Deploy from a branch را انتخاب کن.
5. Branch را روی `main` و پوشه را روی `/(root)` بگذار و Save را بزن.
6. پس از انتشار، آدرس HTTPS سایت را باز کن.

## نصب
- Android: آدرس سایت را با Chrome باز کن، منوی سه‌نقطه را بزن و `Install app` یا `Add to Home screen` را انتخاب کن.
- Windows: آدرس سایت را با Chrome یا Edge باز کن؛ از نوار آدرس یا منوی مرورگر گزینه‌ی `Install` / `Install this site as an app` را انتخاب کن.

## اطلاعات
کارها در localStorage همان مرورگر/دستگاه ذخیره می‌شوند. بنابراین نصب روی گوشی و ویندوز، به‌خودی‌خود اطلاعات را بین دو دستگاه همگام‌سازی نمی‌کند. برای همگام‌سازی باید بعداً قابلیت حساب کاربری یا ذخیره‌سازی ابری اضافه شود.
